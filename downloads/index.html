Integrity Check

Verifying Release Signatures & Checksums

Full Verification Guide

It is essential that you verify the integrity of downloaded files using the PGP signatures (.asc) or SHA-512 checksums (.sha512). Always fetch the KEYS file and signature files directly from https://downloads.apache.org/manifoldcf/, never from third-party mirrors.

GPG & SHA-512 Verification Commands
# 1. Download and import the official ASF KEYS file (from downloads.apache.org)
curl -fsSLO https://downloads.apache.org/manifoldcf/KEYS
gpg --import KEYS

# 2. Verify PGP signature
gpg --verify apache-manifoldcf-2.31-bin.tar.gz.asc apache-manifoldcf-2.31-bin.tar.gz

# 3. Verify SHA-512 checksum
gpg --print-md SHA512 apache-manifoldcf-2.31-bin.tar.gz | diff - apache-manifoldcf-2.31-bin.tar.gz.sha512
