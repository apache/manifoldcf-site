Release 2.31 · Java 25 LTS & Virtual Threads Spring Boot 4.2 in trunk

Enterprise Content Integration with Native Security Trimming

Apache ManifoldCF™ is an open-source framework for crawling, transforming, and indexing documents from heterogeneous enterprise repositories into Apache Solr, OpenSearch, Elasticsearch, Kafka, HDFS, and MongoDB—while preserving source-repository Access Control Lists (ACLs).

Why Apache ManifoldCF

Built for Secure, High-Throughput Enterprise Search

Designed from the ground up for incremental multi-repository ingestion, strict document-level security enforcement, and modern cloud-native Java runtimes.

Native ACL Security Trimming

Captures allow, deny, and inherited folder ACLs at crawl time and resolves user access tokens at query time via the Authority Service (/UserACLs).

Java 25 & Virtual Threads

Powered by Java 25 LTS, Project Loom Virtual Threads across CrawlerAgent, AgentsDaemon, and UserACLServlet, plus embedded Jetty 12.1.
