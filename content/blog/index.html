Apache ManifoldCF 2.31 Released: The Java 25 Leap, Virtual Threads, and Next-Gen Core Modernization

Official release of Apache ManifoldCF 2.31 under CONNECTORS-1784: Java 25 runtime baseline, Project Loom Virtual Threads across the crawling engine, Jetty 12.1 modernization, 88,000+ lines of legacy code removed, and automated Docker CI/CD integration testing.
