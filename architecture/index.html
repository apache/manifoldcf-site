Security Trimming

Zero-Leakage Document-Level Security

Every crawled document carries its native repository permissions—allow tokens, deny tokens, and hierarchical parent/share tokens—directly into the target search index.

When an end user searches, your search plugin queries ManifoldCF's Authority Service (/mcf-authority-service/UserACLs) with the authenticated user name. Active tokens are resolved against Active Directory, LDAP, or repository authorities and applied as a search filter query.

Read Document Security Model
Search-Time Security Trimming Filter
# Example Solr Filter Query generated with ManifoldCF Authority Service tokens
fq=(allow_token_document:"group_engineering" OR allow_token_document:"user_jane_doe")
   AND NOT (deny_token_document:"group_restricted")
Next Generation (2.32-SNAPSHOT)

Spring Boot 4.2, Modern Admin Console & GitOps

Building on the Java 25 LTS and Project Loom foundation introduced in Release 2.31, development on trunk adds a unified Spring Boot 4.2 executable WAR alongside the classic Jetty 12.1 distribution:

  • Modern Admin Console (/ui/): Clean browser UI alongside the classic JSP Crawler-UI.
  • REST API v2 (/api/v2/*): OpenAPI 3 specification, Swagger UI, and declarative YAML/JSON GitOps configuration management.
  • Cloud-Native Probes: Unauthenticated /api/v2/health and Spring Boot Actuator readiness endpoints for Kubernetes and Docker.
